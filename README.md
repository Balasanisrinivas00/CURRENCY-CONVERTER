# CURRENCY-CONVERTER

A React Native Expo currency converter application.

## Getting Started

This project was created using Expo and includes React Navigation for screen navigation.

### Prerequisites

- Node.js
- npm or yarn
- Expo CLI (optional, for additional features)

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

### Running the App

- **Web**: `npm run web`
- **iOS**: `npm run ios` (requires macOS)
- **Android**: `npm run android`
- **Development**: `npm start`

### Dependencies

- **Expo**: ~54.0.9
- **React**: 19.1.0
- **React Native**: 0.81.4
- **React Navigation**: 
  - @react-navigation/native: ^7.1.17
  - @react-navigation/native-stack: ^7.3.26
  - react-native-screens: ^4.16.0
  - react-native-safe-area-context: ^5.6.1

## Development

This is a blank Expo template with navigation dependencies pre-installed. Start building your currency converter app by modifying `App.js`.
